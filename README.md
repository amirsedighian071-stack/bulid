# ساخت ربات بدون کدنویسی (Bulid Bot)

## معرفی سامانه
اپلیکیشن وب چندصفحه‌ای (MPA) مدرن برای ساخت و دیپلوی ربات‌های تلگرام و بله بدون نیاز به کدنویسی.

## ویژگی‌های اصلی
- **۳۲ مدل ربات آماده**: از قیمت طلا تا هوش مصنوعی
- **معماری ماژولار**: پلتفرم آداپتر، رجیستری الگوها، مدیریت کانفیگ، و ...
- **دیپلوی خودکار**: روی Cloudflare Workers یا Railway
- **دو زبانه**: فارسی (RTL) و انگلیسی (LTR)
- **دو تم**: روشن و تاریک با افکت‌های نئونی
- **پنل ادمین حرفه‌ای**: دسترسی با `/admin` و شناسه عددی
- **ماژول عضویت اجباری**: کنترل کانال و گروه

## ساختار فایل‌ها
- `index.html`: ساختار صفحات و رابط کاربری
- `styles.css`: استایل‌های Tailwind و افکت‌های نئونی
- `script.js`: منطق معماری، دیپلوی و تعاملات

## نحوه استفاده
1. انتخاب مدل ربات از بین ۳۲ گزینه
2. انتخاب پلتفرم (تلگرام / بله)
3. انتخاب سرویس میزبانی (Cloudflare / Railway)
4. وارد کردن توکن‌ها و شناسه مدیر
5. کلیک بر روی دکمه دیپلوی خودکار

## ماژول‌های معماری
- Platform Adapter
- Bot Template Registry
- Bot Configuration Manager
- Storage Adapter (D1 Database)
- Secret Manager
- Deployment Adapter
- Webhook Manager
- Admin Panel Engine
- Membership Manager
- Broadcast Manager
- User Management
- Statistics Engine
- Logging and Monitoring
- Scheduler
- Queue Manager
- Health Check & Error Handler

## پنل ادمین
- دسترسی: `/admin`
- احراز هویت: تطبیق شناسه عددی ارسال‌کننده
- داشبورد: آمار، درخواست‌ها، خطاها
- مدیریت کاربران و پیام همگانی
- حالت‌های فعال/تعمیر

## ماژول عضویت اجباری
- تعریف کانال/گروه
- پیام عضویت
- دکمه عضویت و بررسی مجدد
